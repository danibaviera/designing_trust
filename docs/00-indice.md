# Índice do projeto

## Visão geral
Este projeto foi estruturado para sair do nível de ideia conceitual e se tornar um case de portfolio com base em service design, pesquisa de usuários, design de experiência e pensamento em risco financeiro.

## Objetivo do portfolio
Mostrar que o projeto não é apenas uma ideia de produto, mas uma proposta realista de melhoria de serviço, estruturada em:

- pesquisa qualitativa;
- mapeamento de jornada;
- blueprint de serviço;
- análise de risco e operação;
- hipóteses de redesign;
- métricas e justificativa de valor.
